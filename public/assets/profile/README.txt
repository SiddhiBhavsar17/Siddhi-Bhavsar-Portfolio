=============================================================================
PROFILE PHOTO ASSETS DIRECTORY (/public/assets/profile/)
=============================================================================

Place your real portrait / profile photo in this folder:
- Recommended file name: profile.jpg (or profile.png, profile.webp)
- The website will automatically load this photo in the Hero profile card and About section.
- Fallback: If no file is present, the portfolio gracefully displays the stylized personal universe avatar.

Configured in: src/data/personalData.ts -> profileImage: "/assets/profile/profile.jpg"
=============================================================================
